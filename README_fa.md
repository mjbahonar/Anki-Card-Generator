# Anki Card Generator

[English guide](README.md) · [یادداشت انتشار](CHANGELOG.md)

این برنامه فهرست کلمات اکسل را به کارت‌های Anki با معنی، مثال، جدول صرف، تصویر و صوت تبدیل می‌کند. انگلیسی و نروژی از یک برنامه و یک فایل کانفیگ استفاده می‌کنند. فقط **`config.toml`** را تغییر بده و **`main.py`** را اجرا کن. استایل فعلی برای همهٔ زبان‌ها حفظ شده و بخش انگلیسی Info پایین همهٔ سورس‌ها قرار دارد.

## نصب و اجرا

پایتون ۳٫۱۱ یا جدیدتر لازم است. سلنیوم، ChromeDriver و تنظیم فایل `.env` لازم نیستند.

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
python main.py --check
python main.py
```

به‌صورت پیش‌فرض کلمات از ستون اول `New Words.xlsx`، بدون عنوان ستون، خوانده می‌شوند. ابتدا با چند کلمه تست کن؛ `input.max_words = 3` اجرای آزمایشی را به سه کلمه محدود می‌کند، و `0` یعنی همهٔ کلمات.

## تنظیمات در یک فایل

| بخش کانفیگ | چه چیزی را تغییر می‌دهد؟ |
| --- | --- |
| `language` | زبان ورودی: `no` برای نروژی، `en` برای انگلیسی؛ زبان ترجمهٔ گوگل، مثلاً `fa` |
| `input` | نام فایل اکسل، نام یا شمارهٔ شیت، وجود هدر، ستون کلمات، حذف تکراری‌ها، تعداد کلمات |
| `sources.*` | روشن و خاموش بودن دیکشنری‌ها و ترتیب نمایش |
| `audio` | اولویت صوت، کش، لهجهٔ انگلیسی، مسیر ذخیره و کپی اختیاری در پوشهٔ رسانهٔ Anki |
| `output` | مسیر خروجی، نوع فایل‌ها، پیشوند نام و ذخیرهٔ بازیابی |
| `anki` | نام دک، شناسهٔ دک و شناسهٔ مدل |
| `style` | فایل استایل مشترک فعلی |
| `runtime` | زمان انتظار شبکه، تلاش مجدد ترجمه، فاصلهٔ بین کلمات و مرورگر مخفی |
| `info` | متن انگلیسی و لینک پایین کارت |

شمارهٔ شیت و ستون از **صفر** شروع می‌شود. برای انتخاب ستون با نام، `header = true` لازم است. مسیرهای نسبی نسبت به محل فایل کانفیگ حساب می‌شوند.

برای خاموش کردن یک سورس، زیر بخش آن `enabled = false` بنویس. برای تغییر ترتیب، بخش‌های `[sources.…]` را در فایل جابه‌جا کن؛ هیچ تغییری در کد استخراج یا پکیج Anki لازم نیست. سورس‌های ناسازگار با زبان انتخاب‌شده خودکار رد می‌شوند.

## انگلیسی و نروژی

تنظیم پیش‌فرض نروژی است: Lexin، Bokmålsordboka، Nynorskordboka، ترجمهٔ فارسی گوگل و Dict.com. Lexin فقط اولین مدخل دقیق کلمه را می‌گیرد و توضیحات، جدول صرف و ترکیب‌های همان مدخل را حفظ می‌کند.

برای انگلیسی `language.source` را `en` کن، اکسل مورد نظر را انتخاب کن و سورس‌هایی مثل Oxford، Fastdic، Cambridge، Faraazin و B-Amooz را فعال کن. ترجمهٔ گوگل نیز قابل استفاده است. Dict.com از جفت انگلیسی–نروژی استفاده می‌کند و برای کلمات انگلیسی معنی نروژی می‌دهد؛ برای دک انگلیسی–فارسی آن را غیرفعال کن. فهرست کامل سورس‌ها و محدودیت‌هایشان در [راهنمای انگلیسی](README.md) آمده است.

برای Fastdic، Cambridge و Oxford تعداد مثال‌های هر معنی با `examples_per_definition` کنترل می‌شود؛ پیش‌فرض سه مثال است و مقدار صفر فقط معنی‌ها را نگه می‌دارد.

فقط صوت خود کلمه دانلود می‌شود؛ صوت صرف‌ها و ترکیب‌ها دریافت نمی‌شود. صوت Lexin اولویت نروژی است و Google TTS جایگزین آن می‌شود. برای انگلیسی Fastdic با لهجهٔ `us` یا `uk` و Google TTS قابل انتخاب‌اند. کش از دانلود دوباره جلوگیری می‌کند. لازم نیست سورس متن یک دیکشنری فعال باشد تا صوتش انتخاب شود.

## دیکشنری‌ها و تصاویر

Oxford تمام نقش‌های دستوری مدخل‌های دقیق همان کلمه را می‌گیرد. Bokmålsordboka و Nynorskordboka دو سورس جدا هستند؛ جدول صرف بازشده و تأکیدهای bold و italic را حفظ می‌کنند. املای Nynorsk ممکن است با Bokmål فرق کند و برای بعضی کلمات مدخل دقیق وجود نداشته باشد.

برای عکس، بخش `[sources.images]` را با `enabled = true` فعال کن. `count = 3` تعداد عکس و `priority = ["google", "commons"]` ترتیب دریافت را تعیین می‌کند. اگر گوگل محدود باشد، تصاویر از Wikimedia Commons دریافت می‌شوند؛ با `["commons"]` فقط Commons استفاده می‌شود. نام پدیدآورنده و اطلاعات مجوز همراه عکس نمایش داده می‌شوند. تصاویر کلمات چندمعنایی را بازبینی کن.

## خروجی‌ها و خطاها

هر ترکیبی از `xlsx`، `csv`، `apkg`، `html` و `json` را در `output.formats` قرار بده. پیش‌نمایش HTML صوت قابل پخش دارد. فایل Anki فقط رسانه‌های استفاده‌شده را در بسته قرار می‌دهد. Info همیشه آخر است.

کنسول وضعیت `OK`، `EMPTY` یا `FAIL` هر سورس، زمان دریافت و وضعیت صوت را نشان می‌دهد. گزارش پایانی تعداد نتایج موفق، خطاها، صوت‌ها و مسیر خروجی‌ها را جمع‌بندی می‌کند.

خطای یک سایت پردازش بقیهٔ منابع و کلمات را متوقف نمی‌کند. گزارش خطا در فایل `*_errors.json` ذخیره می‌شود. ذخیرهٔ بازیابی هر چند کلمه یک CSV می‌سازد؛ مقدار `autosave_every = 0` آن را غیرفعال می‌کند. با Ctrl+C خروجی جزئی ذخیره می‌شود.

Google Translate همچنان ممکن است خطای محدودیت درخواست بدهد؛ تغییر ساختار برنامه این محدودیت سرویس را برطرف نمی‌کند. دریافت همهٔ سایت‌ها هم به دسترس‌پذیری و ساختار فعلی آن‌ها وابسته است.

## شناسهٔ دک

پس از اولین ایمپورت، شناسهٔ دک و مدل را ثابت نگه دار. روشن/خاموش کردن یا جابه‌جایی دیکشنری‌ها ترتیب فیلدهای مدل را تغییر نمی‌دهد؛ شناسهٔ کارت با تغییر محتوا و صوت ثابت می‌ماند. برای ساخت دک مستقل، `deck_id` و نام دک را عوض کن. مدل مشترک می‌تواند بین دک‌های انگلیسی و نروژی مشترک بماند.
